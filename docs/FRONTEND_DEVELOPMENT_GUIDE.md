## 项目结构

### 目录组织原则

**按功能模块组织**:
```
src/
├── components/      # 可复用组件(原子化设计)
```

- ✅ 可复用性高

## 原子化设计

### 设计层级

```
Atoms (原子) → 最小UI单元
    ↓
Molecules (分子) → 简单组合
    ↓
Organisms (有机体) → 复杂功能
    ↓
Templates (模板) → 页面布局
    ↓
Pages (页面) → 完整页面
```

### 组件分类指南

**Atoms (原子组件)**
- 特点: 最小单元,不可再分
- 示例: 标题、按钮、输入框
- 原则: 无业务逻辑,高度复用

**Molecules (分子组件)**
- 特点: 2-3个原子组合
- 示例: 搜索栏、表单字段
- 原则: 简单交互,独立使用

**Organisms (有机体组件)**
- 特点: 复杂功能模块
- 示例: 页面头部、数据表格
- 原则: 包含业务逻辑,功能完整

**Templates (模板组件)**
- 特点: 页面布局结构
- 示例: 通用页面模板
- 原则: 关注布局,提供插槽

**Pages (页面组件)**
- 特点: 完整业务页面
- 示例: 仪表盘、设置页
- 原则: 组合模板,连接数据

### 组件设计原则

1. **单一职责**: 一个组件只做一件事
2. **可组合性**: 易于组合使用
3. **可复用性**: 避免硬编码
4. **一致性**: 遵循Carbon规范
5. **可访问性**: 语义化HTML

## 开发规范

### TypeScript使用

**类型定义**
- 所有函数必须有类型注解
- 避免使用any类型
- 为Props定义接口
- 使用严格模式

**命名规范**
- 组件: PascalCase
- 函数/变量: camelCase
- 常量: UPPER_SNAKE_CASE
- 类型: PascalCase + 后缀(Props/Type)

### 组件开发

**组件结构**
1. 导入依赖
2. 类型定义
3. 组件函数
4. 导出

**Props设计**
- 必需props在前
- 可选props在后
- 提供默认值
- 使用解构

**事件处理**
- 使用useCallback缓存
- 避免内联函数
- 命名以handle开头

### 文件组织

**文件命名**
- 组件文件: ComponentName.tsx
- 样式文件: ComponentName.module.css
- 测试文件: ComponentName.test.tsx
- 类型文件: types.ts

**导出规范**
- 使用命名导出
- index.ts统一导出
- 避免默认导出

## 状态管理

### 状态分类

**本地状态 (useState)**
- 用途: 组件内部状态
- 示例: 表单输入、开关状态
- 原则: 不需要共享的状态

**服务端状态 (React Query)**
- 用途: API数据管理
- 示例: 通话列表、用户信息
- 优势: 自动缓存、重试、更新

**全局状态 (Context)**
- 用途: 跨组件共享
- 示例: 主题、语言、用户信息
- 原则: 真正需要全局的才用

**URL状态 (路由参数)**
- 用途: 可共享的状态
- 示例: 搜索条件、分页
- 优势: 可分享、可刷新

### 状态管理原则

1. **就近原则**: 状态放在最近的父组件
2. **最小化**: 只存储必要的状态
3. **单一数据源**: 避免状态重复
4. **不可变**: 使用不可变更新

## 国际化(i18n)

### 配置结构

**命名空间拆分**
```
locales/
├── zh-CN/
│   ├── common.json      # 通用文本
│   ├── pages.json       # 页面文本
│   └── navigation.json  # 导航文本
├── en-US/
└── ja-JP/
```

### 使用规范

**翻译key命名**
- 使用语义化命名
- 层级不超过3层
- 使用命名空间前缀

**最佳实践**
- 所有文本都要翻译
- 提取重复文本到common
- 使用插值处理动态内容
- 定期检查缺失翻译

## 样式规范

### Carbon Design System

**使用原则**
- 优先使用Carbon组件
- 使用Carbon设计令牌
- 遵循Carbon主题
- 保持视觉一致性

**设计令牌**
- 颜色: var(--cds-text-primary)
- 间距: 基于8px网格
- 字体: IBM Plex Sans
- 圆角: var(--cds-border-radius)

### CSS组织

**CSS Modules**
- 每个组件独立样式
- 避免全局污染
- 使用语义化类名

**样式原则**
- 移动优先
- 响应式设计
- 无障碍支持
- 性能优化
